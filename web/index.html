填写值用于计算和核对，不会修改 PLL、CPU 或供电。晶振频率是板级输入，不能仅从 RCC 测量出来。

② 核对实际时钟

③ 固件计算与建议

PLL1 路径公式

VCO = HSE / M × (N + FRACN / 8192)
CPU = VCO / P / CDCPRE
HCLK = CPU / AHB 分频
TRACECLK = VCO / R / 2
每半周期样点 = LA采样率 / (2 × TRACECLK)

固件负责 HSE、供电、Flash 延迟、PLL、总线/外设/SysTick、缓存/MPU和引脚预留。上位机负责 trace 门控、复用、路由和采集。
